# Dynatrace to Application Insights

An Azure Function that retrieves monitoring data from **Dynatrace** and sends telemetry to **Azure Application Insights** for centralized observability and analysis.

## Main Features

* Retrieve monitoring data from Dynatrace
* Process and transform telemetry data
* Send telemetry to Azure Application Insights
* Integrate Dynatrace monitoring with Azure observability services

## Technologies

* C# / .NET
* Dynatrace API
* Azure Application Insights
* Azure Monitor
* REST API / HTTP
* JSON

## Purpose

This project provides a simple integration layer between Dynatrace and Application Insights, allowing Dynatrace data to be collected and forwarded to the Azure monitoring environment.
